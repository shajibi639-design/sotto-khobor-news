# সত্য খবর নিউজ — রেডিমেড ডেমো এবং অফলাইন অ্যাডমিন

## ডেমো চালু
`index.html` এবং `admin.html` একই ফোল্ডারে রাখুন। মোবাইলে HTML ফাইল সরাসরি খুলে ডিজাইন দেখা যাবে; নির্ভরযোগ্যভাবে পরীক্ষা করতে কম্পিউটারে `python -m http.server 8000` চালিয়ে `http://localhost:8000/index.html` এবং `/admin.html` খুলুন।

## সংবাদ প্রকাশ (Firebase ছাড়া)
1. `admin.html` খুলে সংবাদ যোগ/এডিট/ডিলিট করুন।
2. Backup/Publish থেকে `news.json` ডাউনলোড করুন। Settings-এ ইমেইল, বিজ্ঞাপন ও ঘোষণা বসিয়ে `settings.json` ডাউনলোড করুন।
3. `index.html`, `app.css`, `data.js`, `site.js`, `news.json`, `settings.json` GitHub Pages-এর একই ফোল্ডারে আপলোড করুন।
4. পরের সংবাদ প্রকাশে নতুন `news.json` রিপ্লেস করুন। সাইটের পাঠকরা আপডেটেড সংবাদ পাবেন।
5. `admin.html` ও `admin.js` **পাবলিক সাইটে আপলোড করবেন না**। index.html-এ থাকা `Admin Demo` লিংকটি লাইভে প্রকাশের আগে সরিয়ে দিন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- Firebase/Backend ছাড়া সার্ভার থেকে স্বয়ংক্রিয় পোস্ট প্রকাশ বা নিরাপদ অনলাইন Admin Login নেই। লোকাল ব্রাউজারের ডেটা অন্য ডিভাইসে নিজে থেকে যাবে না। নিয়মিত JSON ব্যাকআপ রাখুন।
- এখানে থাকা ৬টি সংবাদ **কাল্পনিক নমুনা**। বাস্তব সংবাদ নয়। লাইভ প্রকাশের আগে ডিলিট করে যাচাইকৃত মৌলিক সংবাদ দিন।
- পাঠকের ইমেইল অ্যাপ খুলতে `mailto:` ব্যবহৃত হয়েছে। `settings.json`-এ আসল ইমেইল না দিলে যোগাযোগ সম্পূর্ণ হবে না।
- বিজ্ঞাপন ব্যানার স্থান আছে; AdSense অনুমোদন, Analytics, ভিউ অনুযায়ী আয়ের ব্যবস্থা বা SEO ইনডেক্সিং গ্যারান্টি নেই।
- ফাইলের মাধ্যমে `index.html` খুললে ব্রাউজারভেদে localStorage শেয়ার নাও হতে পারে। HTTP-তে পাবলিক সাইট JSON থেকে সংবাদ লোড করে; Admin-এর লোকাল পরিবর্তন আপলোড ছাড়া প্রকাশ হয় না।

## ফাইল তালিকা
`index.html` পাঠকের সাইট; `admin.html` লোকাল এডিটর; `app.css` ডিজাইন; `data.js` ডেমো ও ইউটিলিটি; `site.js` পাবলিক সংবাদ; `admin.js` এডিটর; `news.json` প্রকাশিত সংবাদ; `settings.json` সাইট সেটিংস।
